Each year, the teams behind the major browsers pick a few features to focus on. The goal is to create a stable, targetable platform that developers can be confident in regardless of user browser choice. For the last few years, the team has asked the broader community to weigh in on which features would make the most impact for them. Inspired by [Stuart Robson's](https://www.alwaystwisted.com/articles/and-thats-my-rank-2027-edition) blog post doing the same, I'm sharing the 10-ish features I picked for next year in [the developer survey](https://developer-signals.rviscomi.workers.dev/).

## `Temporal`

`Date` sucks. It's a giant pain to work with, and causes untold headaches when you can't be certain where it will be created, manipulated, or formatted for display. Thankfully, `Temporal` fixes all that _while_ adding additional functionality. Unfortunately, it is not currently supported in Safari -- though it is already in the Technical Preview build. Might have been a "wasted" vote given that, but I need this to land as soon as possible for mental health reasons.

Recommended reading: ["Date is out, Temporal is in" by Mat Marquis](https://piccalil.li/blog/date-is-out-and-temporal-is-in/).

## Anchor Positioning

Gotta be honest: this one is purely selfish. The little underline in the header navigation on this site is a single anchor-positioned element where the anchor scope changes based on `:hover`/active state. And it technically works in all major browser engines...but Chromium is the only one that will animate it. Other than that I have not found a single issue with anchor positioning between browsers. But my animation!

Recommended reading: [this Bluesky post from Kevin Powell that I ~~stole the technique from~~ used as reference](https://bsky.app/profile/kevinpowell.co/post/3mu5l7cav4s2a).
